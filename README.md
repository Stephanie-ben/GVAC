# Record Management System

A dues and record management system built for Golden Voices Alumni Chorale (GVAC), Lagos Zone.

The system replaces a manual, spreadsheet-based process for managing member dues and payment records with a searchable member experience and an authenticated admin platform for financial officers.

## What I built

I designed and built the product end-to-end, from product structure and interaction design through implementation and deployment.

- Member record search and payment history
- Admin dashboard and member management
- Payment recording and allocation
- Financial rules for dues and outstanding balances
- Admin authentication
- Responsive web experience
- Analytics and automated tests

## Built with

React · Vite · Node.js · Express · PostgreSQL · Neon · Render

## Note on privacy

The repository does not contain production credentials or the real member/payment dataset. Production environment variables and historical source data are kept outside the repository.
